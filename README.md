# Chronic Care – Chronic Disease Management System

A web application designed to manage patient records and monitor chronic disease measurements.

## Features
- Add and manage patient records.
- Record blood glucose measurements.
- Track blood pressure readings.
- Record LDL cholesterol measurements.
- Visualize measurement trends using charts.

## Technologies
- HTML, CSS, JavaScript
- Node.js
- Express.js
- SQLite
- Chart.js

## Run Locally
1. Install dependencies:
   npm install

2. Start the server:
   node server.js

3. Open:
   http://localhost:3000
